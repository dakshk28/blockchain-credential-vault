# Legacy prototype (not used by the application)

These three pages (`index.html`, `upload.html`, `verify.html`) are the original single-file prototype that the project started from. They are kept only to document how the project evolved, for the report. The running application uses `vault/templates/`.

The prototype's in-memory `blockchain.py` was removed in Phase P5. The real blockchain layer is described in [docs/blockchain.md](../blockchain.md).
